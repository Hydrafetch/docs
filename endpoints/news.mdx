---
title: "News"
description: "Find recent news articles about anything, newest first, each with its outlet and publish time."
---

`POST /v1/web/news` finds news articles about a query and returns them newest first. Every article comes with the outlet that published it and when it was published, and each link points at the publisher's own page. Turn on `scrapeResults` and each article also comes back read as clean data.

## When to use it

- You track announcements: funding rounds, acquisitions, launches, leadership changes, layoffs.
- You want what happened this week about a company or a topic, not the pages that rank best for it.
- You feed an agent that needs dated sources it can cite.

For general web pages, use [Search](/endpoints/search). News answers "what was reported, and when"; search answers "which pages are about this".

## Example request

<CodeGroup>

```bash cURL
curl -X POST https://api.hydrafetch.com/v1/web/news \
  -H "X-API-Key: hf_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "startup raises series A",
    "timeRange": "week",
    "limit": 10
  }'
```

```javascript Node
const res = await fetch("https://api.hydrafetch.com/v1/web/news", {
  method: "POST",
  headers: {
    "X-API-Key": "hf_your_key_here",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    query: "startup raises series A",
    timeRange: "week",
    limit: 10,
  }),
});
const { data } = await res.json();
for (const a of data.results) {
  console.log(a.publishedAt, a.source, a.title, a.url);
}
```

```python Python
import requests

res = requests.post(
    "https://api.hydrafetch.com/v1/web/news",
    headers={"X-API-Key": "hf_your_key_here"},
    json={"query": "startup raises series A", "timeRange": "week", "limit": 10},
)
for a in res.json()["data"]["results"]:
    print(a["publishedAt"], a["source"], a["title"], a["url"])
```

</CodeGroup>

## Example response

```json
{
  "data": {
    "query": "startup raises series A",
    "status": "ok",
    "results": [
      {
        "title": "Acme raises $45M in Series A round",
        "url": "https://example.com/news/acme-series-a",
        "source": "Example News",
        "publishedAt": "2026-11-03T09:12:00.000Z",
        "snippet": "The startup raised $45 million to expand into Europe.",
        "imageUrl": "https://example.com/images/acme.jpg",
        "data": null
      }
    ]
  }
}
```

## Key options

<ParamField body="query" type="string" required>
  What to find news about, like `acme raises funding` or `appoints chief executive`. Up to 500 characters.
</ParamField>

<ParamField body="timeRange" type="string" default="week">
  Only articles published within this window before now: `hour`, `day`, `week` or `month`.
</ParamField>

<ParamField body="limit" type="number" default="10">
  How many articles to return, from 1 to 50. Newest first.
</ParamField>

<ParamField body="country" type="string">
  ISO 3166 alpha-2 country code (for example `us`, `gb`, `in`) to lean results toward that country's coverage.
</ParamField>

<ParamField body="includeDomains" type="string[]">
  Only return articles from these sites, like `techcrunch.com`. Up to 15.
</ParamField>

<ParamField body="excludeDomains" type="string[]">
  Drop articles from these sites. Up to 15.
</ParamField>

<ParamField body="maxAge" type="number">
  The oldest earlier answer to the same search you will accept, in milliseconds. By default we reuse an answer up to 5 minutes old for `hour`, 15 for `day` and 30 for `week` or `month`. Set `0` to always search fresh.
</ParamField>

<ParamField body="scrapeResults" type="boolean" default="false">
  When `true`, each article also comes back with its page read and returned as clean data, at **1 extra credit per article read**.
</ParamField>

<ParamField body="scrapeOptions" type="object">
  How to read each article, using the same options as [Scrape](/endpoints/scrape). Ignored when `scrapeResults` is `false`.
</ParamField>

## Response fields

<ResponseField name="data.status" type="string">
  `ok` when articles were found, `no_results` when none matched in the window. If news cannot be searched at all, the request fails with a 503 rather than returning an empty list.
</ResponseField>

<ResponseField name="data.results" type="object[]">
  Articles, newest first. Each has `title`, `url` (the publisher's own page), `source` (the outlet), `publishedAt`, `snippet`, `imageUrl`, and `data`: the article read as clean data when `scrapeResults` is on, otherwise `null`.
</ResponseField>

`publishedAt` is exact when the listing gives a time. Some listings only say how long ago an article appeared, such as "2 days ago", and then `publishedAt` is worked out from that, so it can be off by up to that unit. An article listed more than once comes back once; when several outlets cover the same story, each outlet's article is its own result.

## Billing

A news search costs **1 credit**, and a search that finds nothing is free. With `scrapeResults` on, each article actually read costs **1 more**, the same as scraping that page directly.
