---
title: "Extract"
description: "Get JSON in your schema out of one or many pages, with a confidence and a source for each field."
---

`POST /v1/web/extract` turns pages into JSON in the shape you choose. Describe the shape with a JSON Schema, a plain-language prompt, or both, and an LLM reads each page into it. Point it at one URL, a list, or every page under a path.

Use it when you want specific facts, not the whole page: a product's price and stock, a company's funding round, every listing in a directory.

## When to use it

- You need typed fields, not prose. Give a schema and get exactly those keys back.
- You want the same fields from many pages, or from every page under a path.
- You need to check the result: each field can come back with a **confidence** and the **passage it came from**.
- You want many pages combined into **one list without duplicates**, one row per real thing.

## Example

Get a product's details from one page, with confidence and sources on.

<CodeGroup>

```bash cURL
curl -X POST https://api.hydrafetch.com/v1/web/extract \
  -H "X-API-Key: hf_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "urls": ["https://example.com/products/widget"],
    "schema": {
      "type": "object",
      "properties": {
        "name": { "type": "string" },
        "priceUsd": { "type": "number" },
        "inStock": { "type": "boolean" }
      }
    },
    "showConfidence": true,
    "showSources": true
  }'
```

```javascript Node
import { Hydrafetch } from "@hydrafetch/node-sdk";

const hf = new Hydrafetch(process.env.HYDRAFETCH_API_KEY);
const out = await hf.extract("https://example.com/products/widget", {
  schema: {
    type: "object",
    properties: {
      name: { type: "string" },
      priceUsd: { type: "number" },
      inStock: { type: "boolean" },
    },
  },
  showConfidence: true,
  showSources: true,
});
console.log(out.results[0].data, out.results[0].fields);
```

```python Python
from hydrafetch import Hydrafetch

hf = Hydrafetch()
out = hf.extract(
    "https://example.com/products/widget",
    schema={
        "type": "object",
        "properties": {
            "name": {"type": "string"},
            "priceUsd": {"type": "number"},
            "inStock": {"type": "boolean"},
        },
    },
    showConfidence=True,
    showSources=True,
)
print(out["results"][0]["data"], out["results"][0]["fields"])
```

</CodeGroup>

There is one entry in `results` per page. With `showConfidence`, each has a `fields` map giving, for every field, how sure we are and the passage it came from. With `showSources`, the pages that were actually read are listed in `sources`.

```json
{
  "data": {
    "results": [
      {
        "url": "https://example.com/products/widget",
        "data": { "name": "Widget", "priceUsd": 49, "inStock": true },
        "fields": {
          "priceUsd": { "confidence": 0.92, "evidence": "Priced at $49.00 with free shipping." },
          "inStock": { "confidence": 0.98, "evidence": "In stock, ships today." }
        },
        "error": null
      }
    ],
    "sources": ["https://example.com/products/widget"]
  }
}
```

## Every page under a path

A URL ending in `/*` means every page we find under that path, not a literal address. Each one is read and its results are added. You can mix plain URLs and paths in the same `urls` list.

```json
{
  "urls": ["https://example.com/products/*"],
  "prompt": "Pull the product name, price in USD, and whether it is in stock.",
  "mergeEntities": true,
  "showSources": true
}
```

One call reads at most **20 pages** after paths are expanded, so it costs at most 100 credits. Use `showSources` to see which pages were read. For more pages, run several calls or [crawl](/endpoints/crawl) first and extract from the pages you pick.

## Options

<ParamField body="urls" type="string[]" required>
  The pages to read, up to 10 entries. Each must be http or https. A trailing `/*` means every page under that path.
</ParamField>

<ParamField body="schema" type="object">
  A JSON Schema for the shape you want back. Optional if you give a `prompt`. With both, the schema fixes the field names and types and the prompt says what to look for.
</ParamField>

<ParamField body="prompt" type="string">
  What to extract, in plain language, up to 2000 characters. Use it with a schema or on its own.
</ParamField>

<ParamField body="enableWebSearch" type="boolean" default="false">
  Search the web with your prompt and read up to 5 more pages, to fill fields your URLs do not cover. Needs a `prompt`.
</ParamField>

<ParamField body="showSources" type="boolean" default="false">
  Return the list of pages that were actually read, after paths and web search are expanded.
</ParamField>

<ParamField body="showConfidence" type="boolean" default="false">
  For each field, return a confidence from 0 to 1 and the passage the value came from.
</ParamField>

<ParamField body="mergeEntities" type="boolean" default="false">
  Combine the results from every page into one list without duplicates, one row per thing, each with the pages it came from. Without it you get a separate result per page.
</ParamField>

<ParamField body="preferStructure" type="boolean" default="false">
  Keep headings, lists and tables when reading the page. Good for listing and catalogue pages.
</ParamField>

<ParamField body="maxAge" type="number">
  Use a recent copy of each page if it is younger than this many milliseconds. Leave it out or set `0` to always read fresh. At most 7 days.
</ParamField>

<ParamField body="location" type="object">
  Read each page as if from another place: `country` is a two-letter code, `languages` lists preferred languages in order. For sites that change prices or content by region.
</ParamField>

<ParamField body="headers" type="object">
  Extra headers sent to the site for each page, for example the cookie a shop uses to pick your store, so prices and stock match what you see.
</ParamField>

## Response fields

<ResponseField name="data.results" type="object[]">
  One result per page, each with `url`, `data` (what was extracted, or `null` when nothing matched) and `error` (`null` on success). Includes `fields` when `showConfidence` is on.
</ResponseField>

<ResponseField name="data.results[].fields" type="object">
  For each field name, its `confidence` (0 to 1) and `evidence` (the passage it came from). Only with `showConfidence`.
</ResponseField>

<ResponseField name="data.sources" type="string[]">
  The pages actually read. Only with `showSources`.
</ResponseField>

<ResponseField name="data.collection" type="object[]">
  The combined list, one row per thing. Each row has `data` (all its fields from every page) and `sources` (every page that added to it). Only with `mergeEntities`.
</ResponseField>

## Cost

5 credits per page that returns data. Pages that give nothing are free. A `/*` path or `enableWebSearch` can add pages, so the total depends on how many produce results, up to 20 pages per call. See [Credits](/concepts/credits).
