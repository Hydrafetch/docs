title: "Media"
description: "List every image on a page, or take a screenshot of it."
---

Two endpoints turn a page into images instead of text. **Images** lists every image on a page with its details. **Screenshot** takes a picture of the page as a PNG. Both answer in the same call. Images costs 1 credit. A screenshot costs 5, because the page is always fully rendered.

## Images

`POST /v1/web/images` lists every image on a page with its full address, alt text and declared size. Use it to collect product photos, build an image index, or find the biggest picture on a page.

<CodeGroup>

```bash cURL
curl -X POST https://api.hydrafetch.com/v1/web/images \
  -H "X-API-Key: hf_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{ "url": "https://example.com" }'
```

```python Python
import requests

res = requests.post(
    "https://api.hydrafetch.com/v1/web/images",
    headers={"X-API-Key": "hf_your_key_here"},
    json={"url": "https://example.com"},
)
print(res.json()["data"]["images"])
```

</CodeGroup>

```json
{
  "data": {
    "url": "https://example.com",
    "finalUrl": "https://example.com/",
    "images": [
      { "src": "https://example.com/logo.png", "alt": "Company logo", "width": 320, "height": 240 }
    ]
  }
}
```

<ParamField body="url" type="string" required>
  The page to read. Must be http or https.
</ParamField>

<ParamField body="maxAge" type="number">
  Use a recent copy of the page if it is younger than this many milliseconds. `0` always reads fresh. At most 7 days. See [Caching](/concepts/caching).
</ParamField>

Each image has `src`, made into a full address, and `alt`, `width` and `height`, each `null` when the page does not say.

## Screenshot

`POST /v1/web/screenshot` renders a page and saves it as a PNG. You get back a public link to the image. Use it for visual snapshots, archives, or to show a page to a vision model.

The picture shows the page a reader would see. Cookie banners are accepted, newsletter and anti-adblock pop-ups are closed, ads and trackers never load, and bot-check boxes are hidden, so the screenshot is not mostly a box asking if you are human. A page that is nothing but a challenge is left as it is, because a blank picture would look like success.

<CodeGroup>

```bash cURL
curl -X POST https://api.hydrafetch.com/v1/web/screenshot \
  -H "X-API-Key: hf_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{ "url": "https://example.com", "fullPage": true }'
```

```javascript Node
import { Hydrafetch } from "@hydrafetch/node-sdk";

const hf = new Hydrafetch(process.env.HYDRAFETCH_API_KEY);
const shot = await hf.screenshot("https://example.com", { fullPage: true });
console.log(shot.screenshot);
```

```python Python
import requests

res = requests.post(
    "https://api.hydrafetch.com/v1/web/screenshot",
    headers={"X-API-Key": "hf_your_key_here"},
    json={"url": "https://example.com", "fullPage": True},
)
png_url = res.json()["data"]["screenshot"]
png = requests.get(png_url).content
```

</CodeGroup>

```json
{
  "data": {
    "url": "https://example.com",
    "finalUrl": "https://example.com/",
    "status": 200,
    "screenshot": "https://media.hydrafetch.com/screenshots/3f1c2a.png",
    "screenshotType": "fullPage",
    "width": 1920,
    "height": 4210,
    "cached": false
  }
}
```

### Options

<ParamField body="url" type="string" required>
  The page to capture. Must be http or https.
</ParamField>

<ParamField body="fullPage" type="boolean" default="false">
  Capture the whole scrollable page instead of only the first screen.
</ParamField>

<ParamField body="viewport" type="string" default="desktop">
  The screen size to render at: `desktop` (1920 by 1080), `laptop`, `tablet` or `mobile`.
</ParamField>

<ParamField body="viewportWidth" type="number">
  An exact screen width in pixels, from 320 to 3840. Overrides `viewport`.
</ParamField>

<ParamField body="viewportHeight" type="number">
  An exact screen height in pixels, from 240 to 2160. Overrides `viewport`. With `fullPage`, the picture still covers the whole page.
</ParamField>

<ParamField body="waitFor" type="number">
  Extra milliseconds to let the page settle before the picture, up to 30000.
</ParamField>

<ParamField body="timeout" type="number">
  The time budget for the call in milliseconds, from 1000 to 100000.
</ParamField>

<ParamField body="maxAge" type="number">
  Reuse a saved screenshot younger than this many milliseconds. The default is 7 days, so asking again for the same page and options returns the saved PNG at once with `cached: true`, without applying `waitFor`. Set `0` to take a new one.
</ParamField>

### Response fields

<ResponseField name="data.screenshot" type="string">
  A public link to the PNG. It stays the same for the same URL and options.
</ResponseField>
<ResponseField name="data.screenshotType" type="string">
  `fullPage` or `viewport`.
</ResponseField>
<ResponseField name="data.width, data.height" type="number">
  The image size in pixels.
</ResponseField>
<ResponseField name="data.cached" type="boolean">
  `true` when a saved screenshot was reused.
</ResponseField>
<ResponseField name="data.status" type="number">
  The HTTP status the page returned.
</ResponseField>

## Cost

| Call | Credits |
| --- | --- |
| Images | 1 |
| Screenshot, new or reused | 5 |

Failed calls are free. See [Credits](/concepts/credits).
