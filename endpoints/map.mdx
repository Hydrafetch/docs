---
title: "Map"
description: "List a site's URLs in seconds, without reading the pages."
---

`POST /v1/web/map` lists the URLs on a site without reading any of them. It answers in one call and costs 1 credit, which makes it the quickest way to see what a site has before you crawl it.

## When to use it

- You want to see how big a site is before running a [Crawl](/endpoints/crawl).
- You want a list of URLs to filter and then read with a [Batch](/endpoints/batch).
- You want every URL that contains a word, such as every page with `pricing` in its address.

Map returns addresses only, not content. To read the pages, pass the URLs to Scrape, Batch or Crawl.

## Example

<CodeGroup>

```bash cURL
curl -X POST https://api.hydrafetch.com/v1/web/map \
  -H "X-API-Key: hf_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com",
    "search": "pricing",
    "limit": 1000
  }'
```

```javascript Node
import { Hydrafetch } from "@hydrafetch/node-sdk";

const hf = new Hydrafetch(process.env.HYDRAFETCH_API_KEY);
const site = await hf.map("https://example.com", { search: "pricing", limit: 1000 });
site.links.forEach((l) => console.log(l.url, l.lastmod));
```

```python Python
from hydrafetch import Hydrafetch

hf = Hydrafetch()
site = hf.map("https://example.com", search="pricing", limit=1000)
for link in site["links"]:
    print(link["url"], link["lastmod"])
```

</CodeGroup>

```json
{
  "data": {
    "url": "https://example.com",
    "links": [
      { "url": "https://example.com/pricing", "lastmod": "2026-10-28T00:00:00.000Z" },
      { "url": "https://example.com/pricing/enterprise", "lastmod": null }
    ],
    "count": 2,
    "total": 2,
    "truncated": false

```

## Options

<ParamField body="url" type="string" required>
  The site to list. Must be http or https.
</ParamField>

<ParamField body="limit" type="number">
  The most URLs to return, from 1 to 5000.
</ParamField>

<ParamField body="search" type="string">
  Keep only URLs that contain this word, such as `"pricing"`. Up to 200 characters.
</ParamField>

<ParamField body="sitemap" type="string">
  How to use the site's published page list (its sitemap): `include` it alongside links found on the page, use it `only`, or `skip` it.
</ParamField>

<ParamField body="includeLinks" type="boolean" default="false">
  Also add links found on the starting page, not only the site's page list.
</ParamField>

<ParamField body="sitemapInclude" type="string">
  For sites that publish several page lists, only read the lists whose address contains one of these comma-separated words. For example `"post"` to reach a blog's articles, or `"pages"` to reach a shop's information pages instead of its products.
</ParamField>

<ParamField body="sitemapExclude" type="string">
  Skip page lists whose address contains any of these comma-separated words. Combine it with `sitemapInclude`, for example include `"post"` and exclude `"tag,category,author"`.
</ParamField>

<ParamField body="order" type="string" default="newest">
  `newest` lists the most recently changed pages first, `oldest` the least recent, and `sitemap` keeps the order of the site's own list. Pages with no date come last.
</ParamField>

<ParamField body="includeSubdomains" type="boolean" default="false">
  Also list URLs on the site's subdomains.
</ParamField>

<ParamField body="ignoreQueryParameters" type="boolean" default="false">
  Treat URLs that differ only in their query string as one URL.
</ParamField>

<ParamField body="before" type="string">
  For paging through a large archive from newest to oldest: return only URLs last changed at or before this ISO 8601 time. See below.
</ParamField>

<ParamField body="offset" type="number">
  Skip this many results, then return the next `limit`. Use it to page through sites whose page lists have no dates.
</ParamField>

## Response fields

<ResponseField name="data" type="object">
  <Expandable title="MapResult">
    <ResponseField name="url" type="string">The site you asked for.</ResponseField>
    <ResponseField name="links" type="object[]">Each URL found, as `url` and `lastmod`: when the site's page list says the page last changed, or `null` when it does not say.</ResponseField>
    <ResponseField name="count" type="number">How many URLs this response holds.</ResponseField>
    <ResponseField name="total" type="number">How many URLs the whole list has. Use it to know when you have paged to the end.</ResponseField>
    <ResponseField name="truncated" type="boolean">`true` when the site was too large to list completely in one go. `total` is then a lower bound, not the site's real size.</ResponseField>
  </Expandable>
</ResponseField>

## Paging through a large site

`limit` returns the **most recently changed** pages first, not an even sample of the site. On a site where one kind of page changes all the time, such as a shop's product pages, a small limit can return only that kind. Use `sitemapInclude` to reach the rest.

To get more than one page of results:

- **When pages have dates**, pass the oldest `lastmod` from the previous response as `before`, and remove any URL you already have.
- **When they do not**, step `offset` through `0`, `limit`, `2 × limit` and so on, until `offset + count` reaches `total`. Do not stop just because a page came back short.

## Cost

1 credit per call, however many URLs come back. A call that finds no URLs is free.
