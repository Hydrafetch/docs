---
title: "Search"
description: "Search the web and get ranked results, optionally with each page read as clean data."
---

`POST /v1/web/search` runs a query against the web and returns ranked results. Turn on `scrapeResults` and every result also comes back with its page read and cleaned, so one call turns a question into documents your model can use.

## When to use it

- You know what you are looking for but not the exact URLs.
- You want the top few sources on a topic as clean Markdown.
- You want results from a recent window, a region or a set of sites.

For recent articles with dates, use [News](/endpoints/news) instead. Search answers "which pages are about this"; News answers "what was reported, and when".

## Example

<CodeGroup>

```bash cURL
curl -X POST https://api.hydrafetch.com/v1/web/search \
  -H "X-API-Key: hf_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "best open source vector databases",
    "limit": 3,
    "timeRange": "month"
  }'
```

```javascript Node
import { Hydrafetch } from "@hydrafetch/node-sdk";

const hf = new Hydrafetch(process.env.HYDRAFETCH_API_KEY);
const { results } = await hf.search("best open source vector databases", {
  limit: 3,
  timeRange: "month",
});
results.forEach((r) => console.log(r.rank, r.title, r.url));
```

```python Python
from hydrafetch import Hydrafetch

hf = Hydrafetch()
found = hf.search("best open source vector databases", limit=3, timeRange="month")
for r in found["results"]:
    print(r["rank"], r["title"], r["url"])
```

</CodeGroup>

Each result has a rank, title, URL and snippet. With `scrapeResults` on, each also has `data`, the page read as clean data. Otherwise `data` is `null`.

```json
{
  "data": {
    "query": "best open source vector databases",
    "status": "ok",
    "results": [
      {
        "title": "Best open source vector databases",
        "url": "https://example.com/vector-databases",
        "snippet": "A rundown of the leading open source vector databases and how they compare.",
        "rank": 1,
        "data": {
          "url": "https://example.com/vector-databases",
          "finalUrl": "https://example.com/vector-databases",
          "status": 200,
          "metadata": { "title": "Best open source vector databases", "pageType": "article" },
          "markdown": "# Best open source vector databases\n\n..."
        }
      }
    ]
  }
}
```

## Options

<ParamField body="query" type="string" required>
  What to search for, up to 500 characters.
</ParamField>

<ParamField body="limit" type="number" default="5">
  How many results to return, from 1 to 15.
</ParamField>

<ParamField body="scrapeResults" type="boolean" default="false">
  Also read each result's page and return it as clean data, at **1 extra credit per page read**. Leave it off to get just the title, URL and snippet.
</ParamField>

<ParamField body="scrapeOptions" type="object">
  How to read each result, with the same options as [Scrape](/endpoints/scrape): `formats`, `location`, `timeout`, `maxAge` and so on. Formats are limited to `markdown`, `html`, `rawHtml`, `links` and `structured`. Ignored when `scrapeResults` is off.
</ParamField>

<ParamField body="timeRange" type="string">
  Only results from the last `day`, `week`, `month` or `year`.
</ParamField>

<ParamField body="country" type="string">
  A two-letter country code, such as `us` or `de`, to lean results toward that country.
</ParamField>

<ParamField body="includeDomains" type="string[]">
  Only return results from these sites. Up to 15.
</ParamField>

<ParamField body="excludeDomains" type="string[]">
  Leave out results from these sites. Up to 15.
</ParamField>

## Response fields

<ResponseField name="data.status" type="string">
  `ok` when results were found, `no_results` when the web had nothing for the query. If the search cannot be run at all, the call fails with `503` instead of returning an empty list.
</ResponseField>

<ResponseField name="data.results" type="object[]">
  The ranked results. Each has `title`, `url`, `snippet`, `rank` and `data`.
</ResponseField>

## Cost

1 credit per search. With `scrapeResults`, each page actually read costs 1 more, the same as scraping it directly. A search that fails costs nothing. See [Credits](/concepts/credits).
