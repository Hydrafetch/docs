## Your first call

Send a URL and get clean Markdown back. New workspaces start with 500 free credits for 30 days, and a scrape costs 1.

<CodeGroup>

```bash cURL
curl -X POST https://api.hydrafetch.com/v1/web/scrape \
  -H "X-API-Key: $HYDRAFETCH_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "url": "https://example.com" }'
```

```ts TypeScript
const res = await fetch("https://api.hydrafetch.com/v1/web/scrape", {
  method: "POST",
  headers: {
    "X-API-Key": process.env.HYDRAFETCH_API_KEY!,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ url: "https://example.com" }),
});

const { data } = await res.json();
console.log(data.markdown);
```

```python Python
import os, requests

res = requests.post(
    "https://api.hydrafetch.com/v1/web/scrape",
    headers={"X-API-Key": os.environ["HYDRAFETCH_API_KEY"]},
    json={"url": "https://example.com"},
)
print(res.json()["data"]["markdown"])
```

</CodeGroup>

Every endpoint lives under one base URL: `https://api.hydrafetch.com/v1/web`. The [Quickstart](/quickstart) walks through the response.

## Building with an agent

Every page of these docs is also plain Markdown: add `.md` to its URL. The API describes itself at [`/openapi.json`](https://api.hydrafetch.com/openapi.json) and [`/mcp/tools`](https://api.hydrafetch.com/mcp/tools), and neither needs a key.

The quickest start is to let your agent read our agent guide and wire things up:

```text Prompt
Read https://hydrafetch.com/agents.md and set up Hydrafetch in this project.

Use the HYDRAFETCH_API_KEY environment variable, never a hardcoded key. Then make one scrape call against a URL that is relevant to what this project does, and show me the markdown it returns and what it cost.
```

We also publish skills that teach an agent our API. [`where-to-use-hydrafetch`](https://hydrafetch.com/.well-known/agent-skills/where-to-use-hydrafetch/SKILL.md) looks through a codebase for where Hydrafetch fits, and the [full index](https://hydrafetch.com/.well-known/agent-skills/index.json) covers reading pages for context, company research, schema extraction and building datasets.
