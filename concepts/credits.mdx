---
title: "Credits & billing"
description: "One currency for every call, charged only when you get a result, and every response says what it cost."
---

Every call is priced in **credits**. A scrape, a crawl, a search and an extraction all use the same balance, and there are no separate meters. Your **workspace** holds the balance, and every key in the workspace spends from it.

## You pay only for results

A call is charged only when it gives you data. If it fails, it costs nothing. That covers a bad key, an invalid request, a page we could not read, a page behind a wall and a timeout.

<Note>
  Because failures are free, retrying is safe. You are never billed for a call that produced nothing.
</Note>

The balance is checked before any work starts. If your workspace cannot cover a call, it is refused straight away with `402` and nothing runs:

```json
{
  "success": false,
  "error": { "code": "INSUFFICIENT_CREDITS", "message": "Insufficient credits" },
  "meta": { "requestId": "019e8a3c-9f0b-7c12-88ab-1d2e3f4a5b6c" }
}
```

## What each call costs

| Call | Credits |
| --- | --- |
| [Scrape](/endpoints/scrape) | 1. Add 1 for the `summary` format, 4 for `json`, and 5 for `brand` when a brand is found. See [Formats](/concepts/formats). |
| [Map](/endpoints/map) | 1, however many URLs come back. Free when it finds none. |
| [Crawl](/endpoints/crawl) and [Batch](/endpoints/batch) | 1 per page read |
| [Search](/endpoints/search) | 1, plus 1 for each result read with `scrapeResults` |
| [News](/endpoints/news) | 1, plus 1 for each article read with `scrapeResults`. Free when nothing is found. |
| [Extract](/endpoints/extract) | 5 per page that returns data |
| [Brand](/concepts/brand) | 5 per company found. Searching brands we already hold is free. |
| [Styleguide](/concepts/brand) | 10 |
| [Logo](/endpoints/logo) as JSON | 1 |
| [Logo](/endpoints/logo) as an image | Counted against your plan's logo allowance, not credits |
| [Screenshot](/endpoints/media) | 5 |
| [Images](/endpoints/media) | 1 |
| [Jobs search](/endpoints/jobs) | 1 per 10 jobs returned. Free when nothing matches. |
| [Hiring changes](/endpoints/jobs) | 1 per company we have jobs for |
| [Rate a result](/endpoints/feedback) | Free |

A page served from our cache costs the same as a fresh read. The cache makes calls faster, not cheaper.

## Every response says what it cost

A scrape response has a `usage` object:

```json
{
  "usage": {
    "creditsUsed": 1,
    "creditsRemaining": 499,
    "freshness": "fresh"
  }
}
```

<ResponseField name="creditsUsed" type="number">
  What this call took from your balance.
</ResponseField>

<ResponseField name="creditsRemaining" type="number">
  What is left in your workspace after this call.
</ResponseField>

<ResponseField name="freshness" type="string">
  `fresh` when the page was fetched for this call, `cache` when it came from a recent copy. See [Caching](/concepts/caching).
</ResponseField>

For crawls and batches, the job's status shows `creditsUsed` so far as it runs.
