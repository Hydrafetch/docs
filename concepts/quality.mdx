---
title: "Extraction quality"
description: "Every scrape says how far to trust it: a confidence score, a completeness flag and a blocked flag."
---

Some pages come back perfect. Others come back thin, cut short or behind a wall. If your pipeline cannot tell them apart, bad pages end up next to good ones. So every scrape carries a `quality` object, and your code can decide page by page whether to use the result, retry it or set it aside.

```json
{
  "data": {
    "url": "https://example.com/article",
    "quality": {
      "confidence": 0.94,
      "complete": true,
      "blocked": false
    }
  }
}
```

All three are worked out from the page itself, without an LLM. The same page always scores the same, and the check adds no cost or delay.

## `confidence`

A number from `0` to `1`. We measure the page's content in more than one independent way and compare the results. When they agree on a good amount of content, confidence is high. When the page gives almost nothing, or the measurements disagree, confidence drops.

| Confidence | What to do |
| --- | --- |
| 0.8 or more | Use it. The content was substantial and the measurements agreed. |
| 0.4 to 0.8 | Usable, but check it if the page matters. Something made the page hard to read. |
| Below 0.4 | Treat it as unreliable. The result is thin, empty or blocked. |

## `complete`

`true` when the result holds most of the content the page has. `false` when it looks thin or cut short compared with the page. If you asked for the whole page with `onlyMainContent: false`, the result is always complete, because nothing was left out.

## `blocked`

`true` when the page seemed to be behind a challenge or a bot wall and no real content came through. A blocked result always has low `confidence` and `complete: false`.

A blocked result costs nothing and is never cached, so asking again later fetches the page again rather than repeating the bad copy. When we cannot read a page at all, the call fails with `422` and `UPSTREAM_UNREACHABLE` instead. See [Errors](/concepts/errors).

## Using it in a pipeline

```python
from hydrafetch import Hydrafetch

hf = Hydrafetch()
page = hf.scrape(url)
q = page["quality"]

if q["blocked"]:
    retry_later(url)
elif q["confidence"] < 0.4 or not q["complete"]:
    flag_for_review(url, page)
else:
    ingest(page["markdown"])
```
